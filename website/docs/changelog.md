## v1.5 — Aug 2026

- Added a portable Agent Skill and OpenAI plugin package as the primary adoption path.
- Added one canonical machine manifest, state schema, generated spec aliases, header, skill references, and site material.
- Added a deterministic typed runtime, structural repair, transcript reconstruction, and provider-neutral host adapter.
- Made tag indexes conversation-global across loci and made every valid user `!<c>` advance cycle, capped at 3.
- Added stateless remote MCP, JSON/OpenAPI operations, immutable resources, and a start prompt for Cloudflare Workers.
- Added installable repository marketplace metadata, deterministic plugin and
  skill downloads, privacy and terms routes, and OpenAI domain-verification
  support.
- Preserved v1.4 protocol artifacts and kept corpus schema v1.5 versioning independent.
