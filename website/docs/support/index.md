Viable Prompt Protocol is an open-source project published by **Seb Suarez**.

## Get help

- For installation, protocol, or runtime questions, [open a GitHub issue](https://github.com/cbassuarez/viable-prompt-protocol/issues).
- For private support, security coordination, privacy questions, or terms questions, email [contact@cbassuarez.com](mailto:contact@cbassuarez.com).
- For implementation details, read the [installation guide](/install/), [VPP v1.5 specification](/spec/), and [validator documentation](/validator/).

When reporting a problem, include the plugin or protocol version, host, relevant operation, and a minimal reproducible example. Remove API keys, authentication material, private transcripts, and other sensitive content before sharing logs or opening a public issue.

## Service status checks

- Runtime health: [`https://mcp.viableprompt.org/healthz`](https://mcp.viableprompt.org/healthz)
- OpenAPI document: [`https://mcp.viableprompt.org/api/v1/openapi.json`](https://mcp.viableprompt.org/api/v1/openapi.json)
- Source repository: [`cbassuarez/viable-prompt-protocol`](https://github.com/cbassuarez/viable-prompt-protocol)

The MCP URL is `https://mcp.viableprompt.org/mcp`. It expects MCP requests and is not intended to render a browser page.

## Policies

Review the [privacy policy](/privacy/) for data handling and retention, and the [terms of service](/terms/) for permitted use and service limitations.
