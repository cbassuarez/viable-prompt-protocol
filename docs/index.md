# Viable Prompt Protocol documentation

The public documentation for the Viable Prompt Protocol is now published via the VitePress site at
<https://viableprompt.org/>.

- For the generated human specification, use [`docs/spec/v1.5/spec.md`](spec/v1.5/spec.md). The normative
  machine source is [`protocol/v1.5/manifest.json`](../protocol/v1.5/manifest.json).
- For the latest header snippet, fetch
  <https://cdn.jsdelivr.net/gh/cbassuarez/viable-prompt-protocol@main/docs/spec/v1.5/header-snippet.txt>.
- For deterministic adoption, install the plugin under [`plugins/viable-prompt-protocol`](../plugins/viable-prompt-protocol)
  or use its remote MCP dependency. The header is a reduced-assurance fallback.
- For experiment logs and corpus assets, browse the [`/experiments/`](../experiments/) and [`/corpus/`](../corpus/)
  directories in this repository.

This file remains in place so CDN mirrors and legacy bookmarks continue to resolve.
The human-facing site is powered by VitePress.
